# Ryxen Pocket 🐾

Cute Android-приложение на Jetpack Compose + Supabase Auth.

## Что уже сделано
- Вход и регистрация через Supabase Email/Password.
- Username передаётся в Supabase user metadata для профиля.
- Главная вкладка с общей статистикой.
- Заметки: создание, редактирование, удаление.
- Избранное для заметок.
- Настройки и выход из аккаунта.
- Проверка совпадения паролей при регистрации.
- Улучшенный экран заметок и более аккуратная типографика.
- Локальное сохранение заметок через SharedPreferences.
- Cute-навигация внизу приложения.

## Supabase
Используется только publishable key клиента. Service role/secret key в приложение не помещается.

## Сборка APK без ПК
Этот проект можно собрать через облачную Android-среду/CI с Android SDK и Gradle (например, GitHub Actions или другой Android build service). На телефоне достаточно загрузить проект, запустить Gradle build и скачать `app-debug.apk`/`app-release.apk` из артефактов. Для release APK дополнительно нужна подпись.

## Локальные заметки
Заметки пока не синхронизируются с Supabase: они хранятся на устройстве. Это сделано намеренно, чтобы базовая версия приложения работала без отдельной таблицы notes и RLS-политик.


## APK без ПК

В проект уже добавлен GitHub Actions workflow `.github/workflows/build-apk.yml`. После загрузки проекта в GitHub можно запустить workflow из вкладки **Actions**. Готовый debug APK появится в разделе **Artifacts** как `RyxenPocket-debug-apk`.

Это debug-сборка для установки и тестирования. Для публикации в Google Play или распространения как подписанного релиза понадобится отдельная release-подпись.
